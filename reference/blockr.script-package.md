# blockr.script: Script and Prose Blocks for 'blockr'

A block for 'blockr' boards whose state is an ordinary R script. The
script reads any number of upstream results and returns whatever its
last statement evaluates to. A top-level assignment of a plain value
becomes a control on the block, and the exported code is the script with
the current values written in. A prose block holds markdown with inline
R, as 'Quarto' writes it, and reads its inputs the same way.
